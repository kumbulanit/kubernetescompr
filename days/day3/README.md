## Learning objectives

By the end of this topic you can:

1. Say when a ConfigMap change reaches a running pod, and when it does not
2. State what a Secret actually protects against
3. Explain that ReadWriteOnce means one NODE
4. Justify why a database is a StatefulSet and a gateway is not
