## Learning objectives

By the end of this topic you can:

1. Explain why an unused ServiceAccount token is a liability
2. Prove every RBAC grant AND every denial with `kubectl auth can-i`
3. Install the whole platform in one command, and roll it back
4. Make the SLO a query, and alert on the absence of traffic
