# Day 5 — Security, packaging and operations

This day is about running the platform in a safer and simpler way.

The main ideas are simple:
- give pods the identity they need
- use RBAC to control access
- use Helm to package resources
- move the same release through environments
- use metrics, logs, and alerts to spot problems early

For every lab in this day:
1. Read the lab README.
2. Apply the manifest or chart.
3. Check the result.
4. Run the validation command.
