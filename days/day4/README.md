## Learning objectives

By the end of this topic you can:

1. State the four networking rules Kubernetes requires of any CNI
2. Choose between the five Service types and defend the choice
3. Derive the DNS egress rule after default-deny breaks everything
4. Tell 404, 502 and 503 apart and name the layer each belongs to
